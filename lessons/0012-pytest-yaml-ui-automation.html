4. 核心概念 × 5（{{var}} 替换 / 探针机制 / 业务码 bug / UI 路径 1 / 缺包降级）

4.1 概念 1：YAML 数据驱动 + {{var}} 模板替换（substitute + SafeDict）

硬编码 10 条用例的致命伤：每条用例都要手写一段 Python 代码；改一条断言 / 加一条 case / 改一处 schema 都要 4-5 个文件来回切。YAML 数据驱动的修法：把"用例逻辑"（Python 测试函数）和"用例数据"（yaml 文件）解耦——同一个 test_func(case) 跑 N 条 yaml case。

本课的 7 个 yaml 文件 + 47 条 case，每条 case 触发一个 parametrize id（如 test_prod_info[加购成功-探针 prodId]）；每条 case 的 body / query / path 可能含 {{skuId}} / {{addrId}} / {{basketId}} 等动态变量。

substitute + SafeDict 核心代码（common/yaml_loader.py）：

class SafeDict(dict):
    """dict 子类：缺 key 时返回 '{{key}}' 字面，避免 KeyError 崩溃。"""
    def __missing__(self, key):
        return "{{" + key + "}}"

def substitute(value, mapping):
    """递归替换 dict/list/str 里的 {{var}} 占位。"""
    if isinstance(value, str):
        return value.format_map(SafeDict(mapping))
    if isinstance(value, dict):
        return {k: substitute(v, mapping) for k, v in value.items()}
    if isinstance(value, list):
        return [substitute(v, mapping) for v in value]
    return value

def pytest_yaml_cases(path: str, key: str):
    """读 YAML 数据文件的 key 列表，用于 parametrize。"""
    import yaml
    with open(path, encoding="utf-8") as f:
        data = yaml.safe_load(f)
    return data[key]
SafeDict 金句
"SafeDict 让 yaml 写错时立刻看到 {{key}} 字面"——如果用 str.format 缺 key 会抛 KeyError，整个 collect 阶段崩；用 SafeDict 返回字面占位，下游 params.body.skuId = "{{skuId}}" 被发送到后端 → 后端返回 A00014 业务码失败，用例 FAIL（不是 ERROR），用户立刻看到"哦 probe 没跑通"。这才是优雅降级。

4.4 概念 4：Playwright 路径 1 降级（API 拿 token + cookie 注入 + 跳 home，绕过滑块）

mall4v 前端登录链路（front-end/mall4v/src/views/common/login/index.vue 行 106-130）有三层障碍：

  1. blockPuzzle 滑块验证码（@/components/verifition/Verify.vue）—— 第三方 aj-captcha 组件，绕过难度高（轨迹识别 + 后端二次校验）
  2. AES-ECB-PKCS7 加密（crypto.js）—— 密码 encrypt(password) 走前端 AES；Python 端已用 common/mall4j_aes.py 兼容
  3. 路由跳转 + cookie 注入—— 登录成功后 cookie.set('Authorization', data.accessToken) + router.replace({ name: 'home' })

        # 2. 注入 cookie + 跳首页
        base = BasePage(page)
        admin_url = os.getenv("ADMIN_WEB_URL", "http://localhost:8085")
        base.inject_auth_cookie(token, admin_url)
        base.goto(admin_url + "/", timeout=5000)
        base.wait_for_url("/home", timeout=3000)

        # 3. 截图存证
        base.screenshot("ui-evidence/test_admin_login.png")
路径 1 金句
"UI 测试不一定要走前端表单"——路径 1 用 API 拿 token + cookie 注入等价于前端 cookie.set('Authorization', token)。优点：完全绕开滑块 + AES；缺点：没"真填表单"——D8 才上路径 2（page.route("**/adminLogin", lambda r: r.fulfill(...)) + page.route("**/captcha/**", ...) mock + 真实填表单）。

4.5 概念 5：缺包优雅降级（conftest.py 顶层 try/except + 双层 skip）
