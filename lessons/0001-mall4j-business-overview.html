1. 一句话定位

mall4j 是 B2C 单商户电商开源系统，前后端分离，一套后端同时支撑管理后台、小程序、uni-app 三端前端，业务闭环覆盖商品 → 购物车 → 订单 → 支付 → 后台发货 → 数据统计全链路。

来源：doc/1-项目概览/1-项目介绍.md 第 3 行："Mall4j 开源版是一个 Java B2C 单商户商城系统，采用前后端分离架构。"

5. 核心交易链路（商品/SKU → 购物车 → 确认订单 → 提交订单 → 支付 → 后台发货）

来源：doc/6-核心业务/1-核心交易链路.md 第 6 行。

商品/SKU  →  加入购物车  →  确认订单  →  提交订单  →  支付  →  后台订单管理（发货）

每个环节的接口入口（来自核心交易链路文档第 23-26 行）：

环节接口入口类关键方法
商品浏览ProdController、SkuController商品和 SKU 读取
购物车ShopCartController加车/改数/删除/统计
确认订单OrderControllerconfirm：生成快照写入 ConfirmOrderCache
提交订单OrderControllersubmitOrders：从缓存创建订单+订单项
支付PayController生成支付流水 + 更新支付状态
后台订单管理端 OrderController查询/详情/发货/导出

关键设计（影响测试）：

  • 确认订单结果先放 ConfirmOrderCache，提交时读取。
  • 提交订单后清理确认订单缓存+购物车下单时清理购物车缓存。
  • 支付成功发布事件，后续逻辑通过事件扩展——这是性能压测时需要关注的扩展点。
不建议新手先改的地方
库存扣减/返还、支付状态流转、订单状态流转、订单自动取消/确认收货——影响交易一致性。
