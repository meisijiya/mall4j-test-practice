§1 locustfile 最小骨架

HttpUser + 3 @task + on_start

import sys
sys.path.insert(0, '../api-auto')

from locust import HttpUser, task, between
from common.mall4j_aes import encrypt_password

NUM_USERS = 100
SPAWN_RATE = 10
RUN_TIME = "60s"
HOST = "http://127.0.0.1:8086"

class Mall4jUser(HttpUser):
    wait_time = between(1, 3)

    def on_start(self):
        ts = str(int(time.time() * 1000))
        encrypted = encrypt_password(ts, "test123456")
        resp = self.client.post("/adminLogin", json={
            "username": "testuser",
            "password": encrypted,
            "captchaVerification": "mock-bypass"
        })
        self.token = resp.json()["data"]["accessToken"]

    @task(60)
    def view_prod_list(self):
        self.client.get("/prod/prodList?page=1&size=20",
                       headers={"Authorization": self.token})

    @task(30)
    def view_prod_detail(self):
        self.client.get("/prod/prodInfo?prodId=1")

    @task(10)
    def view_my_info(self):
        self.client.get("/p/user/info")

§2 两种运行模式

Web UI vs Headless

# 模式 1：Web UI（开发调参）
locust -f locustfile.py --host=http://127.0.0.1:8086
# 浏览器打开 http://localhost:8089 → 输 100/10/60s → Start

# 模式 2：Headless（CI / 自动化）
locust -f locustfile.py \
    --host=http://127.0.0.1:8086 \
    --users 100 --spawn-rate 10 --run-time 60s \
    --headless --only-summary \
    --html reports/locust-report.html \
    --csv reports/locust-stats

§3 run-locust.sh 一键脚本

Windows Git Bash 必须 GEVENT_BACKEND=select

#!/usr/bin/env bash
set -euo pipefail
export GEVENT_BACKEND=select   # Windows libuv 兼容坑

REPORTS_DIR="${REPORTS_DIR:-reports}"
mkdir -p "$REPORTS_DIR"

locust -f locustfile.py \
    --host="${MALL4J_HOST:-http://127.0.0.1:8086}" \
    --users 100 --spawn-rate 10 --run-time 60s \
    --headless --only-summary \
    --html "$REPORTS_DIR/locust-report.html" \
    --csv "$REPORTS_DIR/locust-stats"

§4 stats 字段速查

9 个核心指标

  • # Requests：总请求数
  • # Fails：失败数（错误率 = #Fails / #Requests）
  • Median：中位数延迟（ms）
  • 95%ile / 99%ile：P95 / P99 延迟
  • Average：平均延迟（注意：被极端值拉偏）
  • Min / Max：最快 / 最慢
  • Average size：平均响应字节
  • Current RPS：当前瞬时 RPS
  • Current Failures/s：当前瞬时失败数

§5 6 件非显然 fix

踩坑清单

  1. AES 复用 lesson 0012 — sys.path.insert + from common.mall4j_aes import encrypt_password
  2. try/except ImportError — locust 包缺失时优雅降级到 stub
  3. adminLogin 而非 /login — 后端 LoginController 走 /adminLogin
  4. GEVENT_BACKEND=select — Windows Git Bash 必须
  5. NUM_USERS=100 顶部常量 — 不用命令行 --users
  6. CSV DictReader 解析 — csv.DictReader 直接读 stats.csv

§6 异常阈值标注

什么算"性能瓶颈"

  • TPS < 30 → 单实例 Spring Boot 极限，警告"考虑分布式"
  • P99 > 2000ms → 单接口性能瓶颈，警告"考虑缓存/索引"
  • 错误率 > 1% → 后端异常，警告"检查 mall4j-api 日志"
  • JVM full GC → java -Xmx512m -jar 调优
