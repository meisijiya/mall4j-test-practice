2. 5 业务码断言模板

来源：doc/3-API接口/M1-D5-001-impl-notes.md §1.2

模板业务码含义覆盖JS 模板
T-A'00000'成功26pm.expect(String(j.code)).to.eql('00000');
T-B'A00001'业务异常（密码错/count=0/basketIds 空）3pm.expect(String(j.code)).to.eql('A00001');
T-D'A00014'@NotBlank 参数校验2pm.expect(String(j.code)).to.eql('A00014');
T-E'A00005'服务端异常（AES 解密/短信非手机号）1pm.expect(String(j.code)).to.eql('A00005');
T-F!='00000'宽松（鉴权 401/短信默认关/状态机）8pm.expect(String(j.code)).to.not.eql('00000');

铁律：mall4j ServerResponseEntity.code 是 String。Postman 默认 to.eql(200) 永远 FAIL。显式 String(j.code) 是 D5 必修课。

4. 探针机制速查

来源：test-cases/postman/mall4j-api-collection.json 行 798-949

探针请求提取写回失败降级
L3.1GET /prod/prodInfo?prodId=1j.data.prodIdprodId 双写prodId=1
L3.2GET /sku/getSkuList?prodId={{prodId}}j.data[0].skuId || j.data[0].idskuId 双写skuId=1

L3.1 写回伪代码：

var _j = pm.response.json();
if (_j && _j.data && _j.data.prodId) {
  var _v = _j.data.prodId;
  pm.collectionVariables.set('prodId', String(_v));   // 双写 1/2
  pm.environment.set('prodId', String(_v));            // 双写 2/2
}

为什么探两次：/prod/prodInfo 返回单个 ProdDto，/sku/getSkuList 返回 List<SkuDto>。两次 GET 让"先验证商品、再验证 SKU"语义清晰。
